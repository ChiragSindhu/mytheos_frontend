Welcome to MYTHEOS

An autonomous multi-agent debugging swarm. Here's how to get the most out of it.

1
Submit Code
Paste Python code into the CODE tab, or drag & drop a .py file in the FILE tab. Click Run Analysis or hit Ctrl+Enter.
2
Pipeline Panel (left)
The neon path visualization lights up as each agent activates - Input → Strategy → Parallel Analysis → Root Cause → Fix → Tests → Review → Output.
3
Live Phase Streaming (center)
Every phase streams in real-time with a thinking indicator and elapsed time. Results appear as each agent completes - not just at the end.
4
Session Details (right)
Track elapsed time, agent count, tokens, API calls, confidence, and severity. The event log shows a real-time timestamped stream.
5
Try the Sample
Hit SAMPLE to load a buggy Python class with division-by-zero, null dereference, and missing validation - to see MYTHEOS in action immediately.
Requires MYTHEOS API server on localhost:8000
